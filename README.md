# AI Resume Analyzer & Job Recommendation System

An AI-based web application that analyzes resumes, detects technical skills, calculates a resume score, performs ATS keyword analysis, provides improvement suggestions, and recommends suitable job roles based on the candidate's skills.

## Features

- Resume PDF upload
- Automatic resume text extraction
- Technical skill detection
- Resume score calculation
- Score breakdown
- ATS keyword analysis
- Resume improvement suggestions
- Job recommendations
- Skill match percentage
- Missing skill identification
- Resume analysis report download
- Simple and user-friendly web interface

## Technologies Used

- Python
- Streamlit
- PDF Text Extraction
- Regular Expressions
- HTML/CSS
- Machine Learning concepts
- Git

## Project Modules

### 1. Resume Upload
The user uploads a resume in PDF format.

### 2. Resume Text Extraction
The system extracts readable text from the uploaded resume.

### 3. Skill Detection
The application identifies technical skills such as Python, Java, JavaScript, HTML, CSS, Git and Machine Learning.

### 4. Resume Scoring
The resume is evaluated based on technical skills and important resume sections.

### 5. ATS Analysis
The system checks important keywords and provides an ATS keyword score.

### 6. Job Recommendation
The application compares the detected skills with predefined job-role requirements and calculates a skill match percentage.

### 7. Resume Improvement
The system provides suggestions to improve the resume, such as adding projects, internships, certifications, GitHub and LinkedIn profiles.

### 8. Report Generation
The user can download the resume analysis report.

## Job Roles

The system currently provides recommendations for:

- Web Developer
- Machine Learning Engineer
- Full Stack Developer
- Python Developer
- Data Analyst
